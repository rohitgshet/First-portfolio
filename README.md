## 🚀 Running the Project

### Prerequisites
- [Node.js](https://nodejs.org/) (v18+ recommended)
- `npm`

### Development Server
```bash
# Install dependencies
npm install

# Start development server
npm run dev
```
The application will run locally at: `http://localhost:5173/`

### Production Build
```bash
npm run build
```
Generates production assets in the `dist/` directory.
